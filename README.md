🔥 Herói das Chamas

Herói das Chamas é um mini jogo de exploração desenvolvido utilizando apenas HTML.

O jogador assume o papel de um bombeiro que precisa entrar em uma casa em chamas e encontrar a pessoa que ainda está dentro dela. Para isso, deve explorar os diferentes cômodos e escolher entre as opções de navegação disponíveis em cada local.

🎮 Objetivo

Encontrar o cômodo correto e concluir o resgate com sucesso.

🏠 Como funciona

O jogo começa na rua, em frente à casa. A cada etapa, o jogador visualiza sua localização atual e pode escolher entre os caminhos disponíveis para continuar explorando a casa.

O jogo não fornece dicas sobre o caminho correto. O objetivo é explorar os ambientes e descobrir o caminho até o destino por conta própria.

🛠️ Tecnologias utilizadas

- HTML5

O projeto foi desenvolvido exclusivamente com HTML, utilizando links para realizar a navegação entre os diferentes espaços da casa.

📁 Estrutura

O projeto é composto por diferentes páginas HTML, cada uma representando um espaço da casa, como:

- Rua
- Sala
- Cozinha
- Banheiro
- Quarto
- Segundo quarto

🎯 Finalização

O jogo é concluído quando o jogador encontra o cômodo de destino e recebe a mensagem de conclusão.
